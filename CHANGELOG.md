# Changelog

## 1.0.0 — 2026-11-23

- Initial DeployPilot Windows desktop release.
- FTP, explicit FTPS, implicit FTPS, and SFTP connection profiles.
- Encrypted local credential storage through Electron safeStorage.
- Multi-target deployment with staging swap, direct replace, and diff sync.
- Remote ZIP backups, backup verification, retention, and rollback with safety backup.
- Independent upload-exclude, backup-exclude, whitelist, and server-protect rules.
- Deployment history, logs, diagnostics, hooks, remote browser, and Windows notifications.
